# Alyssa Baaroun's Portfolio

A portfolio built around the universe of investigation.
The visitor doesn't just scroll through a classic portfolio —
they open a confidential file and investigate.

---

## Concept

When you land on the site, you become an investigator.
Each section reveals a new piece of evidence: who I am,
what I can do, my projects. Everything is connected,
like pieces of evidence that the user puts together as they go.

## Visual Identity

- **Beige** : aged paper, old confidential files
- **Dark red** : strong accent, the red threads linking clues
- **Light red** : secondary highlights

## Tech Stack

| Tool | Usage |
|------|-------|
