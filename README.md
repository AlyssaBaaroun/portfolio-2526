# Portfolio Alyssa Baaroun (English below)

Un portfolio construit autour de l'univers de l'enquête.
Le visiteur n'est pas simplement invité à faire défiler un portfolio classique, 
il ouvre un dossier confidentiel et mène l'enquête.

---

## Concept

En arrivant sur le site, le visiteur devient enquêteur.
Chaque section révèle une nouvelle pièce à conviction : qui je suis,
ce que je sais faire, mes projets. Tout est connecté,
comme des pièces à conviction que l'utilisateur assemble au fur et à mesure.

## Identité visuelle

- **Beige** : papier vieilli, vieux dossiers confidentiels
- **Rouge bordeaux** : accent fort, les fils rouges qui relient les indices
- **Rouge clair** : touches secondaires

# Alyssa Baaroun's Portfolio

A portfolio built around the universe of investigation.
The visitor doesn't just scroll through a classic portfolio —
they open a confidential file and investigate.

---

## Concept

When you land on the site, you become an investigator.
Each section reveals a new piece of evidence: who I am,
what I can do, my projects. Everything is connected,
like pieces of evidence that the user puts together as they go.

## Visual Identity

- **Beige** : aged paper, old confidential files
- **Dark red** : strong accent, the red threads linking clues
- **Light red** : secondary highlights

## Tech Stack

| Tool | Usage |
|------|-------|
| WordPress | CMS & structure |
| PHP | Dynamic templating |
| SCSS | Styling & variables |
| JavaScript | Interactions & animations |
